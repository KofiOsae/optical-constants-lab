Theory & interpretation
Rayleigh vs Mie
Size parameter x=2π n_host r / λ₀. Rayleigh is a small-particle approximation requiring small x and small internal phase variation; Mie solves the homogeneous sphere boundary-value problem across size regimes. Neither solves arbitrary particle shapes.
Efficiencies
Cᵢ = Qᵢ πr² and Qext = Qsca + Qabs for passive spheres. Ensemble efficiencies use number-averaged geometric area.
Directional transport
g = ⟨cos θ⟩ weighted by differential scattering cross-section; μs = N ⟨Csca⟩; μs′ = μs(1−g). For polydisperse ensembles, g is scattering-weighted, not number-weighted.
Guided example · SiO₂ particles in PMMA
In Model configuration, select Maxwell–Garnett; load measured PMMA host n,k or an appropriate Cauchy model; select SiO₂ Malitson as the particle model; set wavelength 500–800 nm and film thickness 200 nm. In the middle column enter 0, 0.05, 0.10, 0.20 as comparison fill factors and click Calculate comparison. Change the comparison observable between effective n, ε₁, ε₂ and film R/T/A. The 20% case is exploratory and requires applicability checks. These are example settings, not measured sample properties.
Porous-film and analyte infiltration workflow
1. Import or define host and nanoparticle optical constants. 2. Enter particle fraction f and pore fraction p, keeping f+p ≤ 1. 3. Enter the pore medium index (air ≈ 1 or a measured analyte dispersion). 4. Calculate effective ε and film R/T/A. 5. Change only the pore refractive index and compare optical spectra. Interpret changes as model predictions, not demonstrated sensing performance. Sequential three-phase Maxwell–Garnett depends on mixing order; Bruggeman can have ambiguous roots. Neither automatically includes diffuse scattering.
Dielectric-function parameters
For a Lorentz oscillator specify epsilon_inf and oscillators [{strength, energy_ev, gamma_ev}]. Drude–Lorentz adds plasma_ev and drude_gamma_ev. Energies and damping are in eV, with passive exp(-iωt) convention. Use physically justified bounds and source citations. Sellmeier/Cauchy describe transparent materials only.
Particle size and regime
Size parameter x = 2π n_host r / λ₀. Small x and |m|x support Rayleigh approximations; full spherical Mie is not restricted to the Rayleigh regime. Real aggregates, anisotropic or nonspherical particles require additional modelling. The calculated g and μs′ describe independent spherical scattering, not coherent-film haze.
Fill-factor comparison
The particle volume fraction f is the volume occupied by solid particles divided by the total composite volume. Enter fractions from 0 to 1; 5% is 0.05. The comparison uses the currently selected host, particle, EMA method, wavelength grid and film configuration. A zero-fraction run should recover the host. Export comparison CSV for further analysis.
Applicability
The model assumes spherical particles, a lossless homogeneous host, and independent scattering. At high concentrations, interparticle interactions and multiple scattering can invalidate macroscopic coefficients. Effective-medium predictions and Mie attenuation must not be combined without checking for double counting.
