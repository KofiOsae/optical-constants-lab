Nanoparticle Optics & Effective-Medium Modelling

Isolated research preview · Not the published Optical Constants Laboratory · Synthetic constant-index demonstration

Model configuration

CSV columns: size_nm,count. Use radius_nm or diameter_nm for explicit geometry. For weighted measurements, use number_weight. DLS intensity_weight is not automatically converted to number weights.

The current preview uses wavelength-independent input indices. Mie assumes a lossless host and independent spherical particles. Effective-medium theory assumes subwavelength inclusions. These models describe different approximations and must not be interpreted as equivalent.

Research tools · M4–M8

Material library and FMM interchange

Paste a MaterialRecord JSON object containing wavelength_nm, n, k, provenance and data_license. This checks metadata and generates an FMM-compatible CSV and sidecar.

Ellipsometry inversion

Paste JSON with wavelength_nm, psi_deg, delta_deg and angles_deg. Arrays of Ψ and Δ must be indexed [angle][wavelength]. Constant-n,k single-film inverse model.

Meep 2D external job

Export only. A 2D infinite cylinder is not a 3D sphere. No external execution.

Particle distribution

Number and volume weighting differ. SEM/TEM counts can be entered as a number histogram; DLS intensity data require an appropriate conversion.
