## What's new

- Unified responsive laboratory workspace and compact title-row navigation.
- Single-spectrum, joint multi-spectrum and multilayer R/T optical-constant extraction workflows.
- Progressive fitting, multistart configuration, model parameters, reproducible project save/load, and fitted optical-property and reconstructed R/T views.
- Collapsible measured-spectrum, reference-material and diagnostics sections.
- Physical parameter labels and workbook export enhancements for supported numerical models.
- Scientific fit diagnostics, assisted assessment and reference optical-constant comparisons.
- Anonymous longitudinal usage dashboard with UTC daily aggregates across 7, 30 and 365 days.

## Privacy and deployment

The optional server-backed aggregate database is Neon PostgreSQL. Stored rows contain **UTC day, event category, aggregate count** only. Visits are page loads, **not unique users**. No user ID, browser fingerprint, IP, cookies, filenames, fit parameters or uploaded spectra are persisted in the statistics table. Usage requires `USAGE_DATABASE_URL` to be configured server-side; never commit a credential to the repository.

The production v2 deployment has been confirmed live on the original URL, using the merged production commit above. The separate development/staging workflow remains available for future changes.

## Scientific limitations

- R/T inversion may be non-unique; good spectral residuals alone are insufficient evidence of recovered optical-constant accuracy.
- Finite-band KK/SSKK checks have extrapolation and anchoring limitations.
- Interface effective-medium mixing is not a direct measurement of RMS roughness or diffuse scattering.
- Substrate-coherence assumptions and supported model geometries must be matched to the measurement.
